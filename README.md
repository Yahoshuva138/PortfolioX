## 🛠️ Technical Concepts Demonstrated

### Core Technologies
- **Semantic HTML5:**
  - Standard landmarks: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<figure>`.
  - Accessible form structure: `<form>`, `<label>`, `<input>`, `<textarea>`, `<button>`.
  - Proper heading hierarchy (`<h1>` through `<h4>`).
  - Meaningful metadata, attributes (`alt`, `loading="lazy"`, `aria-label`, `target="_blank"`, `rel="noopener noreferrer"`).

- **Modern CSS3:**
  - **CSS Box Model:** Strict universal box-sizing (`box-sizing: border-box`), precise padding, margins, borders, and border-radiuses.
  - **CSS Grid (`display: grid`):**
    - 2-column split Hero layout (`grid-template-columns: 1.25fr 0.9fr`).
    - 4-column responsive Technical Skills grid (`grid-template-columns: repeat(4, 1fr)`).
    - 3-column Featured Projects showcase (`grid-template-columns: repeat(3, 1fr)`).
    - 2-column WebDev 101 Coursework grid (`grid-template-columns: repeat(2, 1fr)`).
  - **CSS Flexbox (`display: flex`):**
    - Navigation bar item alignment and distribution (`justify-content: space-between`, `align-items: center`).
    - Project and coursework card vertical alignment (`flex-direction: column`, `margin-top: auto` for bottom actions).
    - Tag lists and button groups with fluid wrapping (`flex-wrap: wrap`, `gap: 8px`).
  - **CSS Positioning:**
    - Sticky navigation bar (`position: sticky`, `top: 0`, `z-index: 1000`) with glassmorphic backdrop filter (`backdrop-filter: blur(12px)`).
    - Relative timeline markers and connection lines (`position: relative`, `position: absolute`).
  - **CSS Custom Properties (Variables):**
    - Centralized theme tokens (`:root`) for dark slate background colors, text hierarchy, borders, radii, and typography.
  - **Transitions & Subtle Animations:**
    - Interactive card hover elevation (`transform: translateY(-4px)`, smooth box-shadows).
    - Underline expand transition on navigation links (`::after` pseudo-element).
    - Subtle availability pulse animation on hero status indicator (`@keyframes pulseDot`).
  - **Responsive Design & Media Queries:**
    - Desktop (`> 1024px`), Tablet (`<= 1024px`), and Mobile (`<= 768px`) breakpoints ensuring seamless rendering across any screen size.

## 🧑‍🏫 TA Evaluation & Viva Defense Guide

Use this section to understand and defend every architectural choice made in this codebase:

### Q1: What was your design rationale for this portfolio?
> **Answer:** *"The goal was to create an official, clean, and authentic software engineering portfolio. Rather than relying on AI-generated buzzwords, heavy animations, or distracting visual gimmicks, the focus is placed on clean typography, clear visual hierarchy, generous whitespace, and pure semantic HTML5 and CSS3. It communicates directly who I am, what I study at Scaler School of Technology, what skills I possess, and what projects I have built."*

### Q2: Why did you use CSS Grid in the Skills and Projects sections?
> **Answer:** *"CSS Grid is ideal for two-dimensional layout structures where items must align along both rows and columns. In the Skills section (`grid-template-columns: repeat(4, 1fr)`), it produces a balanced 4-column card layout on desktop that reflows gracefully into 2 columns on tablet and 1 column on mobile. In the Projects section (`repeat(3, 1fr)`), Grid maintains equal-width columns while ensuring consistent row alignment across differing screen dimensions."*

### Q3: Why did you use Flexbox in the Navigation Bar and Cards?
> **Answer:** *"Flexbox excels at one-dimensional item alignment and space distribution along an axis. In the navigation bar, `display: flex; justify-content: space-between; align-items: center;` places the brand logo on the left, navigation links centered, and the action button on the right. In the project cards, `display: flex; flex-direction: column;` with `flex: 1` on the description and `margin-top: auto` on the action container guarantees that bottom buttons remain perfectly aligned regardless of description text length."*

### Q4: What does `position: sticky` and `z-index: 1000` do on the header?
> **Answer:** *"`position: sticky; top: 0;` allows the header to scroll naturally with the document until it reaches the top of the viewport, where it locks in place so navigation links remain accessible at all times. `z-index: 1000` assigns a high stacking context to ensure scrolling page content (such as project images) passes behind the navigation bar. The `backdrop-filter: blur(12px)` adds a subtle translucent frosted-glass effect that keeps text legible while content scrolls underneath."*

### Q5: How do your CSS Transitions and Keyframe Animations work?
> **Answer:** *"All transitions are subtle and functional rather than decorative distractions:
> 1. Cards use `transition: all 0.2s ease-in-out;` combined with `:hover { transform: translateY(-4px); box-shadow: var(--shadow-md); border-color: var(--border-hover); }` to provide tactile feedback.
> 2. Navigation links use a pseudo-element `::after` with `transition: width 0.2s ease;` that smoothly expands an accent underline on hover.
> 3. The hero status badge features a gentle `@keyframes pulseDot` animation that subtly pulses an emerald green dot to indicate project availability."*

### Q6: How is responsive design implemented?
> **Answer:** *"Responsive design is implemented using CSS Media Queries and flexible layouts:
> 1. `@media (max-width: 1024px)`: Reflows 4-column skills and 3-column projects into 2 columns and balances hero spacing.
> 2. `@media (max-width: 768px)`: Collapses multi-column grids (hero, about, coursework, contact form) into clean single-column stacks, adjusts font sizes for comfortable phone reading, and wraps footer items."*

## 📬 Direct Contact Form & EmailJS Integration

The contact section includes integration with **EmailJS** (`@emailjs/browser` v4 SDK) allowing visitors to send messages directly from the browser to `kesaboyinayahoshuva@gmail.com` with real-time feedback (loading states, success notifications, error handling):

### Quick 3-Step Setup for Live Key Activation:
1. Create a free account at [emailjs.com](https://www.emailjs.com/).
2. Add an Email Service (e.g. Gmail linked to `kesaboyinayahoshuva@gmail.com`) &rarr; obtain your **`SERVICE_ID`**.
3. Create an Email Template &rarr; obtain your **`TEMPLATE_ID`**.
4. Under Account > API Keys &rarr; copy your **`PUBLIC_KEY`**.
5. Paste your keys into the configuration block in [`index.html`](index.html) and [`tailwind.html`](tailwind.html):
   ```javascript
   const EMAILJS_PUBLIC_KEY = "YOUR_PUBLIC_KEY";
   const EMAILJS_SERVICE_ID = "YOUR_SERVICE_ID";
   const EMAILJS_TEMPLATE_ID = "template_q1xlr9l"; // Configured!
   ```

> [!NOTE]
> A fail-safe `mailto:` fallback is built-in. If keys are not yet configured or if an API connection fails, the form automatically offers to launch the visitor's mail client with pre-filled fields so no messages are ever lost!
